# Consistency Guard (Jev)

캐릭터 응답 직후 Jev로 설정오류를 판정하고, 오류가 의심되면 별도 연결 프로필로 수정 지시문을 만든 뒤 메인 API로 수정본을 새 스와이프로 추가합니다.

## 검사 항목

| 검사 | 기본 | 내용 |
|---|---|---|
| 캐릭터·유저·세계관·다른 멤버 설정과 모순 | 켜짐 | 카드·페르소나·로어북과 대조 |
| 과거 사건·기억과 모순 | 켜짐 | 요약·벡터 검색 결과, 참메모리(항목별 대조) |
| 현재 상황과 모순 | 켜짐 | 장소·시간·복장·소지품·자세 |
| 아직 안 한 약속·계획을 끝난 일처럼 서술 | 켜짐 | 대기 중이거나 취소된 약속을 반대로 서술 |
| 캐릭터가 알 수 없는 정보를 앎 | 켜짐 | 근거에 ‘모른다’고 명시된 경우만 위반으로 봄 |
| {{user}}의 대사·행동을 대신 씀 | 꺼짐 | |
| [문체] 유저 입력 되풀이 / 같은 내용 반복 / 같은 마무리 패턴 | 꺼짐 | 알림만 하고 수정본은 만들지 않음 |

설정 맨 위 **최근 검수 결과**에서 이 채팅의 최근 5건을 볼 수 있습니다. 통과, 수정본 추가, 재검토 결과 오류 아님, 건너뜀(타임아웃·Jev 실패 등 이유 포함)을 구분해 보여주며, 채팅을 바꾸면 비워집니다.

검사 중에 새 응답이 오면 버리지 않고, 가장 최근 응답 하나를 이어서 검사합니다.

## 참메모리 항목별 대조

참메모리 근거와 ‘과거 사건·기억과 모순’ 검사가 켜져 있으면, 주입된 기억을 한 줄씩 나눠 새 응답과 대조합니다.

1. 기억이 24개를 넘으면 먼저 새 응답과 관련 있는 것만 추립니다.
2. 남은 기억마다 Jev가 `모순 / 모르는 정보를 앎 / 충돌 없음 / 불명` 중 하나를 고릅니다.
3. 기준(기본 0.75)을 넘는 모순만 수정 지시문 모델에 ‘어느 기억과 충돌했는지’와 함께 넘깁니다.

참메모리 주입문이 길어도 가운데가 잘리지 않고, 지시문이 틀린 부분을 정확히 짚습니다. 설정의 **참메모리 항목별 대조**로 끄면 예전처럼 한 덩어리로 검사합니다.

선택형 질문을 쓰므로 Jev 게이트웨이가 이를 지원해야 합니다. **연결 시험**이 항목별 대조까지 함께 확인합니다. 실패하면 범주별 검사만 계속 동작합니다.

## 설치

1. 확장: SillyTavern의 **확장 → 확장 설치**에 이 저장소 주소를 입력합니다.
2. 서버 플러그인: 제브 리콜과 같은 Jev 서버 플러그인(`SillyTavern/plugins/jev-recall/index.js`)을 함께 씁니다. 별도 플러그인은 없습니다.
   0.7.0 이상이면 429·5xx·연결 실패 시 타임아웃 안에서 자동으로 다시 시도합니다.
3. `config.yaml`에서 `enableServerPlugins: true`를 확인하고 SillyTavern을 재시작한 뒤 브라우저를 강력 새로고침합니다.

## 연결 프로필

아래 중 하나를 만들어 선택합니다. 키는 확장 설정에 저장되지 않고, 서버 플러그인이 서버 안에서만 읽습니다.

**Vercel AI Gateway**
- API: Custom (OpenAI-compatible)
- URL: `https://ai-gateway.vercel.sh/v1`
- 모델: `typesafe-ai/jev`
- 키: Vercel AI Gateway API 키

**OpenRouter (권장 방식)**
- API: Custom (OpenAI-compatible)
- URL: `https://openrouter.ai/api/v1`
- 모델: `~typesafe/jev-latest` 또는 `typesafe/jev-1.13`
- 키: OpenRouter API 키

**TypeSafe 공식 API**
- API: Custom (OpenAI-compatible)
- URL: `https://api.typesafe.ai/v1`
- 모델: `jev-latest` 또는 `jev-1.13.0` (`typesafe-ai/jev` 같은 접두사 형식도 자동 변환)
- 키: [console.typesafe.ai](https://console.typesafe.ai/)에서 발급한 API 키

ST의 OpenRouter 프로필도 지원하지만, 모델 목록에 Jev가 안 보일 수 있어 Custom 방식이 더 편합니다.
